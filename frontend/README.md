# BaixeAI — frontend

Next.js 16 (App Router) + TypeScript + Tailwind. Veja o README da raiz para rodar tudo via Docker Compose.

- `npm run dev` — servidor local (proxy de `/api` para `API_INTERNAL_URL`, padrão `http://localhost:8000`)
- `npm test` — testes (Vitest)
- `npm run lint` / `npm run typecheck`
